## Cómo abrir un proyecto

1. Abrir **Unity Hub** → **Add** → **Add project from disk**.
2. Seleccionar la carpeta del proyecto dentro de `Proyectos/` (la que contiene `Assets/` y `ProjectSettings/`).
3. Unity regenera solo las carpetas `Library/`, `Temp/` y `Logs/` (por eso no se suben al repositorio).
